name: add-doc
description: 给代码添加简洁高效的中文注释
---

用户要求给当前代码添加中文注释，遵循以下原则：

1. **简短**：注释不超过一行，避免冗长描述
2. **高效**：只注释关键逻辑、非显而易见的代码
3. **可读性强**：使用清晰的中文表达，准确描述意图

注释规范：
- 函数注释放在函数声明上方，说明功能而非实现细节
- 关键变量注释说明用途，而非类型
- 复杂逻辑注释说明意图和原因
- 避免注释显而易见的代码（如 `i++ // i自增`）
- 使用单行注释 `//` 或块注释 `/* */`，与代码风格一致

示例：
```go
// 计算用户积分，按活跃天数加权
func calcScore(days int) int {
    base := 100  // 基础积分
    return base * days
}
```

请对用户指定的代码添加注释。
